Detailed Description

Fully-connected layer: Z = W*X + b, A = act(Z).

Layout: X is [in × batch] column-major, W is [out × in], b is [out] broadcast column-wise. Activation is applied elementwise via FlexNN::Activations::detail.

Backward: ‘dZ = f’(Z) ⊙ (W_next^T * dZ_next)ordZ = W_next^T*dZ_next` if None.

For Softmax hidden, this uses detail::softmax_backward_hidden via Activations::detail::backward. Last-layer Softmax is fused in NeuralNetwork::backward and never calls this for the last layer. activationParams threaded for LeakyReLU alpha.
