◆ forward() [1/2]

std::pair< Eigen::MatrixXd, Eigen::MatrixXd > FlexNN::Layers::BatchNorm1D::forward ( const Eigen::MatrixXd &  input) const

Forward with batch stats (training) — updates running stats.

Uses batch mean/var per feature (row) across batch*L_out? For 1D case with flattened [F*L × batch] input, we treat each row as a feature and compute mean/var over cols (batch). This matches the flattened Dense/BatchNorm stack where each feature is a separate row.

Parameters
input[F × batch] or [F*L × batch] (each row is a feature)
Returns
Pair (Z, A) where Z is normalized y and A = act(Z) (None)
