Detailed Description

Leaky ReLU with configurable alpha (default 0.01).

alpha is the slope for z <= 0. Historic fixed value 0.01 (v0.1) is kept as kDefaultLeakyAlpha in ActivationParameters.hpp; this header now takes alpha as a parameter so layers can store per-layer ActivationParameters.
