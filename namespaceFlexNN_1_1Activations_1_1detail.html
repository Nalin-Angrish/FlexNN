Softmax hidden backward: dZ = J * upstream per column.

Softmax hidden backward per column: dZ = J * upstream.

For hidden Softmax (disallowed in v0.1 but tested), the Jacobian is J = diag(s) - s s^T where s = softmax(Z) per column. This helper applies J to the upstream gradient column-wise. Last-layer Softmax never calls this — it uses the fused A - Y path.

Note
noexcept: allocates MatrixXd; bad_alloc terminates.
Parameters
sSoftmax output per column (from forward)
upstreamUpstream gradient (W_next^T * dZ_next) per column
Returns
Gradient w.r.t. Z

For each column, s is the softmax output for that column and up is the upstream gradient column (W_next^T * dZ_next for that sample). The Jacobian is J = diag(s) - s * s^T, so J*up = s ⊙ (up - s^T up). Implemented without forming J explicitly for O(n) per column.

Parameters
sSoftmax output per column [out × batch]
upstreamUpstream gradient [out × batch]
Returns
Gradient w.r.t. Z, same shape
