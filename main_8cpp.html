Detailed Description

MNIST example — now uses FlexNN::Layers::Dense + Activations + deterministic seed.

Demonstrates the new modular API: FlexNN::Layers::Dense with FlexNN::Activations::Activation, setRandomSeed, and splitXY with explicit seed. The old stringly-typed FlexNN::Layer(..., "relu") is deprecated but still builds via the shim until removed.
