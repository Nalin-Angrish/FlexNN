Detailed Description

Shared PODs for FlexNN::Layers — LayerType, DType, and per-type Params.

This header is standalone (no Eigen) so both ModelIO and per-layer headers can include it without pulling heavy dependencies. Values are stable on-wire for model.bin (see LLD_FLEXNN §5, §7, Appendix A).
