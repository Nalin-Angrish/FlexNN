◆ Activation

enum class FlexNN::Activations::Activation : uint8_t
strong

Activation function identifier.

Values are stable on-wire (model.bin) — do not reorder. 0 is linear (pre-BatchNorm or debugging). LeakyReLU alpha is configurable per-layer via ActivationParameters (default 0.01, see ActivationParameters.hpp); model.bin v2 stores it as 1 float32 in aux when act==LeakyReLU.

Enumerator
None 

Linear, no activation.

ReLU 

max(0, z)

LeakyReLU 

z>0 ? z : alpha*z (alpha from ActivationParameters)

Sigmoid 

1/(1+exp(-z)), clamped

Tanh 

std::tanh(z)

Softmax 

Stable col-wise softmax — only on last layer in v0.1.

Activation &  out 
)
noexcept

Parse a string into an Activation.

Case-insensitive, trims ASCII whitespace. Accepts canonical names ("relu", "leaky_relu", "leakyrelu", "sigmoid", "tanh", "softmax", "none") and common aliases ("leaky-relu", "lrelu", "linear" for None). Returns false on unknown input without throwing — caller decides whether to treat as None or error.

Note
noexcept: heap allocation for lowercasing may throw bad_alloc and terminate via std::terminate (acceptable for host training; tests use small strings).
Parameters
sInput view (not null-terminated required)
outOutput activation on success
Returns
true if parsed, false otherwise (out unchanged on false)
