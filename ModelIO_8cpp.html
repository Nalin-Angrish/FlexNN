Detailed Description

Implements FlexNN flat binary export/import per LLD_FLEXNN §7.

Why this file exists: FlexNN is the source of truth for training; any runtime (including TinyForge) consumes model.bin without Eigen. The writer is intentionally small (no JSON/Protobuf) and deterministic (little-endian, IEEE floats, CRC).

Layout (all LE, packed, no padding): Main header 20B: magic 0x54464E47, version 1, header_len 20, layer_count, flags 0, header_crc32 (CRC of first 16B) Per-layer 52B: type, act, dtype, in_dim, out_dim, w_cnt, b_cnt, aux_cnt, reserved, w_off, b_off, aux_off, c_in, c_out, k, stride, pad, dilation Blobs: w (float32), b (float32), aux (float32) at absolute offsets Footer: file_crc32 (CRC of whole file except last 4B)
