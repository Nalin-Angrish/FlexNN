Detailed Description

Parameters for a Conv1D layer.

Weight layout: W[outChannels][inChannels*K] row-major logical, stored in Eigen column-major MatrixXd but serialized row-major float32. Bias is [outChannels].

Output length: L_out = (L_in + 2*pad - dilation*(K-1) -1)/stride +1 Must be >=1 or export returns Status error.
